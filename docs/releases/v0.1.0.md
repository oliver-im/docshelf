DocShelf Web brings the HTML reports and Markdown notes scattered across your projects into one local site while keeping their source files in place. This is its first announced early release.

### Included

- Explicit registration of local HTML and Markdown files and recursive folders, grouped by project, with production full-text search and automatic rebuilding after source changes.
- **Add…** from the header or a right-click: enter file or folder paths, choose a project, preview the discovered documents, and add them. **Remove from shelf…** changes only the shelf; originals stay untouched.
- Markdown reading in light and dark themes, including tables, highlighted code, Mermaid diagrams, a page outline, and source-line range links.
- Local HTML reports in an opaque sandbox, with interactive scripts but no access to DocShelf's storage, page, or local actions.
- Browser imports for public GitHub Markdown and published Claude Artifacts.
- A resizable sidebar and document actions for opening, copying links, viewing remote sources, and revealing registered local files in Finder on macOS.
- A portable Node.js watcher, an optional macOS login service at `https://shelf.localhost/`, and an agent skill for registering completed documents.
- A shared shelf with DocShelf for Obsidian, which is released separately.

### Install or upgrade

Use Node.js 24 or newer and a filesystem with symbolic-link support. Follow the [installation instructions](https://github.com/oliver-im/docshelf/blob/v0.1.0/README.md#get-started).

Existing checkouts should stop the watcher, update, run `npm ci`, and restart it. Keep `shelf.local.json`. If you use the macOS login service, uninstall it before updating and reinstall it afterward with the same address, port, and `DOCSHELF_WORKSPACE` settings. Normal macOS setup uses `https://shelf.localhost/`; keep `--direct` when reinstalling a direct-port setup. See the [upgrade guide](https://github.com/oliver-im/docshelf/blob/v0.1.0/docs/local-server.md#updating-an-existing-installation).

Legacy `artifacts.local.json` remains supported with a deprecation warning. Rename it only when `shelf.local.json` does not already exist; otherwise merge the entries you want to keep.

### Shelf format

Existing version 1 shelves keep working. Adding the first folder upgrades the shelf to version 2, which older checkouts and DocShelf for Obsidian 0.1.0 reject rather than silently omitting folder contents. If both apps share a shelf, update both before adding a folder. See [adding files and folders](https://github.com/oliver-im/docshelf/blob/v0.1.0/docs/folders.md).

### DocShelf for Obsidian

The Obsidian plugin is versioned and released separately with plain `X.Y.Z` tags. Install the latest plugin ZIP from the [releases page](https://github.com/oliver-im/docshelf/releases) rather than from this web release. Both apps can use a shelf at the web checkout root; keep its sources relative and its routes lowercase. Obsidian's GitHub registrations and absolute source paths are not supported in a shared web shelf. See [shared setup and limits](https://github.com/oliver-im/docshelf/blob/v0.1.0/docs/unification.md).

### Early-release limits

Full-text search covers registered local documents. Browser-imported Markdown is fetched again on reload and is not available offline, and import bookmarks depend on that browser's saved source links. Private GitHub files and arbitrary remote pages are unsupported. Claude embeds require the owner to allow the DocShelf origin.

Adding and removing documents, live rebuilding, and Finder actions require the loopback watcher; static hosting supports browsing and public-document imports only. Keep the default loopback binding for a personal shelf. See the [security policy](https://github.com/oliver-im/docshelf/blob/v0.1.0/SECURITY.md) for the containment and isolation boundaries.

CI covers Ubuntu, and local verification has covered macOS. Windows and a broad browser compatibility matrix have not yet been verified. During `0.x`, breaking changes will be called out with migration guidance in minor-release notes.
