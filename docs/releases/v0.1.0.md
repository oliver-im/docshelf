DocShelf brings the HTML reports and Markdown notes scattered across your
projects into one shelf for the browser and Obsidian while keeping their source
files in place. This is the first announced early release.

### Included

- Explicit registration of local HTML and Markdown, grouped by project, with
  production full-text search and automatic rebuilding after source changes.
- Markdown reading in light and dark themes, including tables, highlighted
  code, Mermaid diagrams, a page outline, and source-line range links.
- Browser imports for public GitHub Markdown and published Claude Artifacts.
- A resizable sidebar and document actions for opening, copying links, viewing
  remote sources, and revealing registered local files in Finder on macOS.
- A portable Node.js watcher, optional macOS login service, and an agent skill
  for registering completed documents.
- The Obsidian desktop plugin in the same repository, with native editing of
  registered local Markdown, autosave recovery, conflict review, isolated HTML
  reports, search, and source-line links. HTML and remote sources remain read-only.
- A shared shelf and link command for browser, Obsidian, and source references;
  one root dependency install and aggregate workspace verification commands.
- Source containment checks during web builds, rebuilding after registered
  symlinks are retargeted, separate storage for different HTML reports in
  Obsidian, and live refresh of registered Markdown images.

### Install or upgrade

Use Node.js 24 or newer and a filesystem with symbolic-link support. Follow the
[installation instructions](https://github.com/oliver-im/docshelf/blob/v0.1.0/README.md#run-locally).

Existing users should stop the watcher, update the checkout, run `npm ci`, and
restart it. Keep `shelf.local.json`. If using the macOS login service, uninstall
it before updating and reinstall afterward with the same address, port, and
`DOCSHELF_WORKSPACE` settings. Normal macOS setup uses `https://shelf.localhost/`;
keep `--direct` when reinstalling an existing direct-port setup.
See the [upgrade guide](https://github.com/oliver-im/docshelf/blob/v0.1.0/docs/local-server.md#updating-an-existing-installation).

Legacy `artifacts.local.json` remains supported with a deprecation warning.
Rename it only when `shelf.local.json` does not already exist; otherwise merge
the entries you want to retain. The shelf schema remains at version 1.

For desktop Obsidian 1.13.7 or later, run `npm run package:obsidian` from the
repository root and install the generated plugin folder. Existing plugin users
should replace only its packaged files, keeping `data.json` and `recovery/`.
Follow the [plugin guide](https://github.com/oliver-im/docshelf/blob/v0.1.0/packages/obsidian/README.md).
The web release does not automatically attach a plugin bundle or update one
already installed in a vault.

Both apps can use a shelf at the web checkout root. Keep its sources relative
and its routes lowercase. Obsidian's GitHub registrations and absolute source
paths are not supported in a shared web shelf; browser GitHub imports remain in
browser storage. See [shared setup and limits](https://github.com/oliver-im/docshelf/blob/v0.1.0/docs/unification.md).

### Early-release limits

Browser full-text search covers registered local documents. Browser-imported Markdown
is fetched again on reload and is not available offline. Remote import bookmarks
depend on that browser's saved source links. Private GitHub files and arbitrary
remote pages are unsupported. Claude embeds require the owner to allow the
DocShelf origin.

Local HTML is trusted content that can execute scripts on DocShelf's origin.
Keep the default loopback server binding for a personal shelf. Finder actions
require the macOS loopback watcher and are unavailable on static hosting.

Obsidian's report viewer uses isolated sessions and document-scoped loopback
access. Local Markdown saves to its original file with conflict checks and
recovery, but simultaneous writes by other applications are not atomic. External
documents do not join vault indexing, backlinks, graph, or Obsidian Sync.
The plugin's runtime verification covers macOS; its GitHub Markdown becomes
searchable after fetching, while Claude content is not indexed.

CI covers Ubuntu and local verification has covered macOS. Windows and a broad
browser compatibility matrix have not yet been verified. During `0.x`, breaking
changes will be called out with migration guidance in minor-release notes.
